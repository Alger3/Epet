# Worker Service

异步生成与资产处理服务，负责质量门禁、抠图、`pet_spec`、标准立绘、动作、后处理、QA 和 `.epet` 打包。

## 目标结构

```text
worker/
├── worker/
│   ├── steps/           # 单输入/输出、可重试的版本化步骤
│   ├── pipelines/       # 步骤编排和降级策略
│   ├── models/          # 模型适配器，不包含可提交权重
│   ├── qa/              # 自动质量指标与阈值
│   ├── packaging/       # Atlas、manifest、license、黑盒校验
│   └── adapters/        # PostgreSQL、队列、存储、指标
└── tests/               # CPU 单测、黄金样例、GPU 冻结评估入口
```

## 强制规则

- 队列消息只含任务 ID、步骤名和期望任务版本，不含照片、签名 URL 或长期凭据。
- Worker 通过租约/心跳领取任务；重复执行写入新尝试对象，校验后事务提交，不能覆盖用户确认版本。
- 输入错误不重试；网络错误退避；显存不足最多按策略降级重试；未知错误进入死信队列。
- 每一步有最大执行时间、尝试数和 GPU 预算；取消在安全边界生效。
- 模型、工作流、阈值、随机种子和输入版本全部写入运行记录。
- Gate B 未通过时默认使用标准立绘加模板轻动画，不扩张生成动作复杂度。
