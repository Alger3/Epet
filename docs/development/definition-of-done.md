# Definition of Done

> 状态：Active
> 负责人：技术负责人
> 评审人：产品负责人、测试负责人、安全负责人
> 最近更新：2026-07-24
> 更新触发：质量门禁、发布流程、隐私或兼容目标变化

## 通用完成条件

- 功能实现、错误状态、超时、重试和恢复路径均已完成。
- 单元/契约/集成/E2E 测试与风险匹配，严重 Bug 有回归测试。
- 日志、指标、追踪和崩溃报告不含敏感数据。
- 文档、OpenAPI、Schema、迁移和用户文案同步。
- 在目标 Windows 环境完成人工验证并保存证据。
- 与上一稳定版性能基线比较，超阈值变化有解释和批准。
- 监控能发现主要失败，告警链接到已演练运行手册。
- 数据、API、资源包或数据库变化已验证升级、失败恢复与回滚。
- 功能开关、预算和权限遵循最小化原则。

## 变更级附加条件

| 变更 | 额外条件 |
|---|---|
| 桌面窗口 | DPI、多屏、焦点、任务栏、穿透、恢复测试 |
| 宠物包 | Schema、哈希、恶意包、版本兼容、原子安装测试 |
| API 写操作 | 归属、幂等、限流、超时、稳定错误码测试 |
| Worker 步骤 | 租约、心跳、有限重试、取消和重复执行测试 |
| 用户数据 | 收集依据、保留期限、删除状态与备份窗口验证 |
| 发布 | 签名、安装、升级、回滚、SBOM 与许可证证据 |

未通过当前阶段 Gate 的功能不能用“代码已完成”替代阶段验收。
