# ADR-0003：匿名模式使用设备凭据鉴权

> 状态：Accepted
> 负责人：安全负责人
> 评审人：桌面端负责人、后端负责人
> 日期：2026-07-24
> 取代：无
> 被取代：无

## 背景

MVP 不要求账号，但上传、任务、GPU 额度和宠物资源仍需可靠归属。安装 ID 可复制和猜测，不能作为秘密。

## 决策

Rust 首次启动生成设备密钥，私钥优先存入 Windows Credential Manager。客户端通过挑战签名换取短期令牌；服务端每次访问同时校验令牌主体和资源所属设备。安装 ID 仅用于统计，邀请码仅控制资格。

## 代价与后果

- 无账号也具备资源隔离、令牌过期和请求签名能力。
- 私钥丢失后无法恢复旧云端任务；本地已安装宠物仍可使用。
- UI 必须提前解释重装/跨设备限制，删除和额度仍需幂等与风控。

## 重新评审条件

引入账号、跨设备同步或凭据迁移时，用新 ADR 定义身份合并和旧设备资源迁移，禁止回退到安装 ID 鉴权。
