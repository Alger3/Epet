# ADR-0000：决策标题

> 状态：Proposed
> 负责人：决策负责人
> 评审人：受影响模块负责人
> 日期：YYYY-MM-DD
> 取代：无
> 被取代：无

## 背景

说明约束、现状、问题、数据和不做决定的后果。

## 决策驱动因素

- 可验证的因素一；
- 安全、成本、兼容或交付因素二。

## 候选方案

### 方案 A

说明做法、优势、风险和迁移成本。

### 方案 B

说明做法、优势、风险和迁移成本。

## 决策

明确选择、适用范围、生效条件和不在范围。`Proposed` 阶段不得写成已经完成。

## 代价与后果

- 正向后果；
- 负向后果；
- 必须新增的测试、监控和运行手册。

## 验证证据

列出测试环境、样本、指标、报告链接。尚无证据时明确写“待验证”。

## 重新评审条件

列出会使本决策失效的具体阈值、平台变化或新需求。
