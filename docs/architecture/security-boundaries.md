# 安全与信任边界

> 状态：Active
> 负责人：安全负责人
> 评审人：桌面端负责人、后端负责人、发布负责人
> 最近更新：2026-07-24
> 更新触发：新增 Command、capability、外部输入、凭据、文件格式或更新渠道

## 原则

所有照片、宠物包、WebView 输入、队列消息、ID 和远端响应都不可信。权限在最靠近资源的边界验证，客户端提示和不可预测 ID 不构成授权。

## 信任区

| 区域 | 信任级别 | 允许能力 |
|---|---|---|
| React 工坊 WebView | 低 | 调用白名单 Command，展示服务端数据 |
| 桌宠 WebView | 最低 | 读取已校验运行时投影、发送交互事件 |
| Tauri/Rust | 本机受信核心 | 凭据、窗口、本地库、受限文件操作 |
| FastAPI | 服务端控制面 | 鉴权、归属、幂等、配额与命令 |
| Worker | 高风险执行面 | 读取授权任务、GPU、受限对象前缀 |
| CI 签名任务 | 最高敏感 | 仅受保护发布任务可读取签名凭据 |

## Tauri 能力基线

桌宠窗口默认禁止网络、对话框、Shell、剪贴板、全局快捷键注册和任意文件系统。工坊也不能直接获得任意路径权限。每个 Command 实现前必须登记：

| 字段 | 必填内容 |
|---|---|
| command | 稳定命令名 |
| callers | 允许的窗口标签 |
| input | Schema、长度、枚举和规范化规则 |
| resource | 允许访问的目录/记录/窗口 |
| side effect | 写入、删除、网络或系统变化 |
| audit | 脱敏日志和错误码 |
| tests | 未授权窗口、边界输入和失败恢复 |

未经登记和评审不得把新 Command 加入 capability。

## 身份与授权

- 首次启动在 Rust 侧生成不可预测设备密钥，私钥不进入 WebView。
- 优先保存到 Windows Credential Manager；受限文件回退必须有诊断和权限检查。
- 注册与换令牌使用挑战签名；访问令牌短期有效，刷新凭据独立保护。
- 每个上传、任务、尝试和资源查询都同时验证令牌主体与 `device_credential_id` 归属。
- 安装 ID 只用于统计；邀请码只控制资格，二者都不能替代鉴权。

## 文件与宠物包

MVP `.epet` 仅允许 JSON、PNG、WebP，禁止 SVG、HTML、脚本、音频、符号链接和嵌套压缩包。默认上限：压缩 30 MB、解压 100 MB、100 个文件、单文件 32 MB、压缩比 20:1。

安全加载顺序：包外大小/哈希 → 随机临时目录 → 流式枚举 → 路径和扩展名 → 累计资源上限 → 文件哈希 → JSON Schema → 帧引用与 Atlas 边界 → 黑盒加载 → 原子移动 → 数据库事务。

任何失败都删除临时内容且不影响已有版本。拒绝绝对路径、`..`、驱动器前缀、NUL、符号链接、大小写冲突与清单外文件。

## 网络和日志

- 上传/下载 URL 短期有效且限制对象键、方法、大小和 Content-Type。
- 错误响应不暴露对象键、堆栈、其他资源是否存在或内部拓扑。
- 日志、指标、追踪、埋点和崩溃报告禁止照片、宠物名、令牌、签名 URL、对象键和完整本地路径。
- 桌面端只加载打包的本地受信内容；CSP 禁止任意远端页面和内联脚本。

## 发布密钥

Windows 代码签名凭据与 Tauri 更新签名私钥分开保管。普通 PR、开发机和未受保护分支不得读取它们。发布前必须在干净 VM 验证篡改安装包、更新清单或签名会被拒绝。

## 验证

发布阻断测试至少覆盖：伪装图片、Zip Slip、压缩炸弹、任务 ID 越权、过期/重放令牌、日志脱敏、capability 过宽、远程内容注入、依赖高危漏洞和更新签名篡改。
