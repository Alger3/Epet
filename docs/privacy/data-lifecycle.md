# 数据生命周期与删除规范

> 状态：Proposed
> 负责人：隐私负责人
> 评审人：产品负责人、后端负责人、安全负责人
> 最近更新：2026-07-24
> 更新触发：新增数据、存储、备份、训练用途、保留配置或删除流程

## 原则

最小化收集、目的限定、环境隔离、默认不训练、可查询删除。用户主动删除先撤销访问，再异步清理；“删除完成”必须说明备份自然过期窗口。

## 数据清单

| 数据 | 位置 | 目的 | 默认保留 | 删除方式 |
|---|---|---|---|---|
| 原始本地照片 | 用户选择位置 | 只读输入 | 应用不修改、不复制为长期文件 | 用户自行管理 |
| 清理后的上传副本 | 本地临时目录 | 裁剪、上传、失败恢复 | 任务完成/取消/过期后清理；具体本地上限待实现前冻结 | 客户端清理任务 |
| 云端原图 | 对象存储上传前缀 | 生成输入 | 生成完成或终止后 24 小时内删除 | 自动生命周期 + 主动删除 Worker |
| 中间产物 | 对象存储处理前缀 | 分步重试与 QA | Gate D 前冻结期限，当前不得宣称具体时长 | 生命周期 + 删除 Worker |
| 最终 `.epet` | 对象存储最终前缀/本地 | 下载与再次使用 | 云端期限 Gate D 前冻结；本地由用户控制 | 云端请求/本地回收流程分开 |
| 任务元数据 | PostgreSQL | 恢复、计费、诊断 | Gate D 前根据运营/隐私要求冻结 | 标记不可访问后清理或去标识 |
| 设备凭据 | Credential Manager/数据库 | 匿名鉴权 | 到撤销、设备丢失或策略过期 | 本地撤销 + 服务端禁用 |
| 审计记录 | PostgreSQL/日志系统 | 删除与安全审计 | Gate D 前冻结，不含照片/对象键 | 到期自动清理 |
| 备份 | 隔离备份 | 灾难恢复 | Gate D 前冻结备份窗口 | 不在线恢复已删除数据，随备份自然过期 |

未冻结项是发布阻断项，不能在对外文案中写成已承诺期限。

## 主动删除状态机

```text
requested → processing → completed
                    └──→ failed（有限重试并告警）
```

请求返回 `202` 只表示已接受。Worker 按不可变对象清单逐项删除；对象不存在视为幂等成功。完成记录只保留非敏感结果、时间和备份到期说明。

## 禁止用途

默认不得用用户照片或产物训练/微调模型。未来若需要，必须使用与生成服务分离的明确同意，不得捆绑授权，并提供撤回、数据集版本和输出清理流程。

## 验证

staging 每周用专用测试对象演练，production 每月抽查删除时延。测试需覆盖对象存储临时故障、重复请求、对象已不存在、任务处理中删除和备份窗口说明。
