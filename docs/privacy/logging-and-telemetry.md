# 日志、指标与埋点规范

> 状态：Active
> 负责人：安全负责人
> 评审人：客户端负责人、后端负责人、产品负责人
> 最近更新：2026-07-24
> 更新触发：新增事件、日志字段、崩溃服务、分析供应商或保留策略

## 数据最小化

允许：版本、阶段、稳定错误码、低基数环境标签、耗时、资源用量、脱敏关联 ID。禁止：照片、宠物名、自由文本、访问/刷新令牌、签名 URL、对象键、设备私钥、完整本地路径和高基数用户标签。

## 渠道分离

- 运行日志：诊断具体操作，字段化且分级。
- 指标：聚合成功率、延迟、队列、GPU、成本和删除积压。
- 产品分析：只记录已登记事件，不接受任意属性。
- 崩溃报告：调用栈、版本和设备能力，先在本地脱敏。

产品分析、崩溃报告和运行日志上传分别提供用户开关；安全必需的本地日志也必须有大小和保留上限。

## 事件治理

事件先通过版本化 Schema 校验和脱敏，再进入有界离线队列。新增事件需登记目的、字段、触发点、保留期、用户控制和删除方式。生产拒绝未登记事件和自由文本属性。

## 验证

安全测试注入测试令牌、签名 URL、对象键和本地路径，确认各日志、崩溃、追踪和埋点出口均已移除；任何泄漏为发布阻断问题。
