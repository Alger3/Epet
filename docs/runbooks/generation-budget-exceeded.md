# 生成预算超限运行手册

> 状态：Proposed
> 负责人：产品/后端当值
> 评审人：财务责任人、后端/AI 负责人
> 最近更新：2026-07-24
> 更新触发：成本公式、预算、配额、模型或重试策略变化

预算达到 70% 告警、90% 限流、100% 停止创建新任务。确认指标包含失败重试 GPU 消耗且环境没有混算。100% 时保持新生成关闭，不影响已有本地宠物；已有任务是否完成仅按预先保留预算策略执行，禁止临时无限追加。

按模型、工作流、错误、自动重试和设备风险拆解成本，检查异常流量、重试风暴和配置漂移。恢复前需由预算负责人批准新上限或完成降本/滥用修复，并先以小额度 canary 验证。

记录成本窗口、任务量、成功成本、失败消耗、批准人和新回滚阈值。不得通过漏算失败成本让指标“恢复”。
