# 对象存储故障运行手册

> 状态：Proposed
> 负责人：后端当值
> 评审人：后端负责人、隐私负责人
> 最近更新：2026-07-24
> 更新触发：对象存储、生命周期、签名 URL 或备份策略变化

确认上传、读取、写入、删除和签名 URL 哪些能力受影响。写入或一致性异常时关闭新上传和新生成；删除受影响时升级隐私事件并监控积压。不得删除 PostgreSQL 元数据来“修复”对象错误。

检查服务状态、网络/DNS、凭据、桶策略、配额、生命周期规则和最近部署。恢复后使用专用对象执行上传→校验→读取→删除 canary，再恢复 Worker，最后逐步开放入口。对处理中任务根据幂等步骤继续，不覆盖已确认版本。

核对孤儿对象、删除时延、签名 URL 吊销、包哈希和成本。涉及数据丢失或越权时按安全/隐私事故处理。
