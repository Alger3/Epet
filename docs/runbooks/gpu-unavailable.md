# GPU 全部不可用运行手册

> 状态：Proposed
> 负责人：后端/AI 当值
> 评审人：Worker 负责人、产品负责人
> 最近更新：2026-07-24
> 更新触发：GPU 平台、健康检查、降级或任务超时变化

确认所有 GPU Worker 心跳丢失或健康检查失败，并核对是否只是单模型/单可用区。立即关闭新生成，保留已上传/排队任务状态，不让客户端无限加载；本地宠物继续运行。

检查容量配额、驱动/运行时、模型加载、凭据、存储访问、最近工作流发布和租约。不要无上限重启或把失败任务全部同时重试。恢复一个隔离 Worker 后跑合成 canary，验证输出、成本、任务版本和对象提交，再逐步恢复消费者与入口。

结束时记录故障窗口、受影响阶段、丢弃的未提交输出、自动重试成本和是否触发模板动画/备用容量。若涉及 P0，需发布事故复盘。
