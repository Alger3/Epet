# 删除积压运行手册

> 状态：Proposed
> 负责人：隐私/后端当值
> 评审人：隐私负责人、安全负责人
> 最近更新：2026-07-24
> 更新触发：删除状态机、保留期限、备份或对象清单变化

按最老请求年龄、失败率、数据类型和环境确认积压，核对访问是否已在请求时撤销。若可能突破承诺期限或访问未撤销，按 P0 隐私事件处理，并视容量暂停新上传。

检查删除 Worker 心跳/租约、对象存储、数据库锁、清单生成、生命周期和死信。对象不存在视为幂等成功；临时故障有限重试。禁止无审计地手工批量删桶或把请求直接改为 completed。

恢复后优先最老请求，限制并发避免压垮存储，逐项核对对象、元数据、审计结果和备份窗口说明。完成条件是积压回阈值内、最老请求未超期、失败有明确处置，且抽样验证访问已撤销、对象已删除。
