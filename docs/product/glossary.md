| 术语 | 唯一定义 |
|---|---|
| 桌面角色 | 普通应用上方的透明置顶悬浮角色，包括猫咪桌宠与 Q 版人物桌宠，不是桌面图标层或壁纸层 |
| 角色工坊 | 主体选择、人物授权、上传、生成、预览、角色库和设置所在的主窗口 |
| `subject_kind` | 创建时冻结的主体判别字段；首版只允许 `pet_cat` 或 `human_avatar` |
| 人物授权声明 | 上传者确认照片主体为本人或已明确授权成年人的版本化声明，不等同于身份证件或人脸向量 |
| 主照片 | 每次创建必选、决定构图和身份的 `primary` 图片 |
| 补充照片 | 最多两张 `side/detail` 图片；猫咪补充侧面/尾巴/花纹，人物补充发型/服装可见信息 |
| 标准立绘 | 用户确认后冻结、作为所有动作身份来源的角色图 |
| 角色包 | 扩展名 `.epet` 的受限压缩资源，非公开导入格式 |
| 服务端 ready | 云端已完成打包，可申请下载；不表示客户端已安装 |
| 客户端 installed | 下载、校验、原子入库全部成功，可被运行时加载 |
| 任务快照 | PostgreSQL 中带单调版本的当前生成状态事实 |
| 状态通知 | Redis/SSE 发出的变化提示，不是事实或永久事件回放 |
| 模板轻动画 | 用标准立绘制作呼吸、眨眼、尾摆和轻位移的降级动画 |
| Gate | 控制下一阶段投入的证据门禁，不是普通里程碑标签 |
