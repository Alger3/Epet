| 术语 | 唯一定义 |
|---|---|
| 桌面宠物 | 普通应用上方的透明置顶悬浮窗口，不是桌面图标层或壁纸层 |
| 宠物工坊 | 上传、生成、预览、宠物库和设置所在的主窗口 |
| 主照片 | 每次创建必选、决定构图和身份的 `primary` 图片 |
| 补充照片 | 最多两张 `side/detail` 图片，只补充侧面、尾巴或花纹信息 |
| 标准立绘 | 用户确认后冻结、作为所有动作身份来源的角色图 |
| 宠物包 | 扩展名 `.epet` 的受限压缩资源，非公开导入格式 |
| 服务端 ready | 云端已完成打包，可申请下载；不表示客户端已安装 |
| 客户端 installed | 下载、校验、原子入库全部成功，可被运行时加载 |
| 任务快照 | PostgreSQL 中带单调版本的当前生成状态事实 |
| 状态通知 | Redis/SSE 发出的变化提示，不是事实或永久事件回放 |
| 模板轻动画 | 用标准立绘制作呼吸、眨眼、尾摆和轻位移的降级动画 |
| Gate | 控制下一阶段投入的证据门禁，不是普通里程碑标签 |
