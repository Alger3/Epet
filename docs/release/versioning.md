# 版本与兼容规范

> 状态：Active
> 负责人：发布负责人
> 评审人：技术负责人、客户端负责人、后端负责人
> 最近更新：2026-07-24
> 更新触发：渠道、更新协议、契约或兼容策略变化

- 客户端/包使用 SemVer；预发布渠道使用 `-alpha.N`、`-beta.N`、`-rc.N`。
- API 主版本在路径中；兼容增加保留 `/v1`，删除、改义或收紧合法输入需新主版本或迁移窗口。
- JSON Schema 使用整数 `schema_version`；读取方拒绝未知更高版本并提示升级。
- `.epet` 同时包含 `package_version` 与 `min_runtime_version`，后者高于客户端时不得尝试加载。
- 模型、工作流、模板和阈值独立版本化；任务记录固定具体版本，禁止生产中原地修改。
- 数据库迁移只追加，遵循 expand → 发布兼容代码 → 迁移使用 → 后续 contract。

模型/工作流放量与客户端放量分开，避免同时改变两个主要变量。
