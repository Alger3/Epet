# Windows 兼容矩阵

> 状态：Proposed
> 负责人：测试负责人
> 评审人：桌面端负责人、发布负责人
> 最近更新：2026-07-24
> 更新触发：支持声明、Windows/WebView2/GPU 基线或窗口实现变化

## 平台

- Windows 11 x64 当前受支持版本：正式发布阻断项。
- Windows 10 22H2 x64 / ESU：尽力兼容；安全或数据问题会撤销兼容声明。

## 每个发布候选的矩阵

| 维度 | 取值 | 证据 |
|---|---|---|
| DPI | 100%、125%、150%、200% | 位置、脚底、拖拽、缩放截图/日志 |
| 显示器 | 单屏、左右双屏、上下双屏、热插拔、主次切换 | 宠物不留屏外 |
| GPU | 集成、独立、WebGL 设备丢失 | FPS、恢复或静态降级 |
| 系统状态 | 锁屏、睡眠/唤醒、切换用户、注销/关机 | 暂停、持久化、恢复 |
| 桌面环境 | 任务栏四边/自动隐藏、Explorer 重启、全屏应用 | 不抢焦点、不阻挡关键操作 |
| 生命周期 | 首装、覆盖升级、更新失败、回滚、卸载保留/删除数据 | 干净 VM 记录 |

报告必须记录 OS Build、GPU、驱动、WebView2、DPI、显示器布局和提交 SHA。实际结果在发布候选报告填写，本模板不预填“通过”。
