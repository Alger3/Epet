### P2-DP-06 负坐标双屏往返回归

- 复现确认拖拽中的异步位置持久化会在鼠标仍按住时按旧显示器裁剪窗口，混合 DPI 返回时同步执行完整恢复还可能把透明窗口缩成 `1×1`；
- 修复后，按住主键期间只延迟收口，松手后使用 Win32 `GetWindowRect` 的物理矩形中心和 `MonitorFromPoint` 选择真实目标显示器，不再混用 Tauri 的 DPI 虚拟化坐标；
- 最终 release 原生窗口回归路径为主屏 `(1100, 600, 320×320)` → 左侧负坐标屏 `(-1500, 500, 320×320)` → 主屏 `(1100, 600, 320×320)`，进程保持响应。

结论：负坐标双屏的原生坐标、边界收口和双向返回自动回归通过；真实手动拖拽手感、不同上下/左右布局和显示器热插拔仍需人工复核。
