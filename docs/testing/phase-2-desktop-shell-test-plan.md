# 阶段 2 桌面壳测试计划

> 状态：Active
> 负责人：测试负责人
> 评审人：桌面端负责人、技术负责人
> 最近更新：2026-07-25
> 更新触发：窗口模型、支持系统、DPI/多屏恢复、托盘或 Gate A 标准变化

## 目的

验证内置离线宠物在目标 Windows 上能稳定显示、恢复和退出，并为 Gate A 提供可复查证据。Linux 前端构建和交叉 `cargo check` 只算预检查。

## 范围

覆盖阶段 2 的双窗口、单实例、托盘、显隐、置顶、穿透、暂停、开机启动、自主移动窗口原型、位置/缩放持久化、DPI、多屏、异常重建和退出。不验证云端生成、宠物包安装、完整随机行为状态机或发布签名。

## 环境矩阵

| 维度 | 阻断环境 | 记录环境 |
|---|---|---|
| OS | Windows 11 x64 最新受支持更新 | Windows 10 22H2 x64 / ESU 尽力兼容 |
| DPI | 100%、125%、150%、200% | 混合 DPI 双屏 |
| 屏幕 | 单屏；双屏左右；双屏上下 | 主副屏交换、负坐标布局 |
| GPU | Intel/AMD/NVIDIA 至少覆盖两类 | 软件渲染仅诊断 |
| 启动 | 正常、二次启动、开机启动 | 升级后首次启动 |

每次执行记录 OS build、GPU/驱动、WebView2、屏幕拓扑、DPI、应用 commit 和构建哈希。截图不得包含个人桌面敏感信息。

## 自动预检查

```bash
npm install
npm --workspace @epet/desktop run typecheck
npm run test
npm --workspace @epet/desktop run build
cargo fmt --manifest-path apps/desktop/src-tauri/Cargo.toml -- --check
```

Windows CI 另执行 `cargo check --all-targets`、`cargo clippy --all-targets -- -D warnings` 和 NSIS 构建。任何失败先修复，不能以手工通过替代。

## 用例

| ID | 操作 | 预期结果 |
|---|---|---|
| P2-LC-01 | 连续启动应用两次 | 只有一个进程逻辑、一个托盘和一个桌宠；工坊被唤醒 |
| P2-LC-02 | 反复关闭/从托盘打开工坊 50 次 | 关闭只隐藏；状态不丢失；无新增窗口/托盘 |
| P2-LC-03 | 模拟桌宠 WebView 异常销毁 | 最多重建一次；再次失败打开诊断入口，无循环 |
| P2-LC-04 | 托盘退出 | 工坊和桌宠结束，无残留 Epet 进程 |
| P2-TR-01 | 工坊/托盘切换显隐、穿透、暂停 | 菜单勾选和两个窗口状态双向一致 |
| P2-TR-02 | 开启后关闭开机启动 | 注册可查询、重启生效、撤销后不再启动 |
| P2-TR-03 | `--autostart` 启动 | 工坊不主动弹出；托盘和桌宠按保存状态恢复 |
| P2-TR-04 | 分别关闭/开启始终置顶并重启 | 原生 `TOPMOST` 标志与保存值一致；普通层级可被其他应用覆盖 |
| P2-DP-01 | 每种 DPI 拖动、缩放、重启 | 脚底位置保持；宠物完整可见；尺寸比例正确 |
| P2-DP-02 | 双屏左右/上下跨屏拖动 | 跨屏连续，保存目标显示器和归一化锚点 |
| P2-DP-03 | 宠物位于副屏时拔掉副屏 | 自动回到匹配屏或主屏工作区，不覆盖任务栏 |
| P2-DP-04 | 改分辨率、DPI、任务栏位置 | 250 ms 防抖后状态稳定，窗口仍在工作区 |
| P2-FC-01 | 桌宠显示期间切换其他应用 | 桌宠不抢键盘焦点，不出现在任务栏/Alt-Tab |
| P2-MV-01 | 开启自主移动并等待触及左右边界 | 窗口以 10 Hz 低频沿工作区底部移动，到边界后反向且不覆盖任务栏 |
| P2-MV-02 | 自主移动期间暂停、隐藏、拖拽，再分别恢复 | 暂停/隐藏/拖拽立即取得优先级；恢复后从有效位置继续，无瞬移出屏 |
| P2-MV-03 | 自主移动中跨 DPI/多屏并运行 30 分钟 | 速度按 DPI 换算；动画与窗口移动时钟独立；位置定期落库且无持续线程/内存增长 |
| P2-OF-01 | 断网后冷启动 | 内置宠物、托盘和设置可用，无网络依赖错误 |
| P2-ST-01 | Windows 11 连续运行 8 小时 | 无崩溃/残留窗口；内存、CPU 无持续单向增长 |

## 通过标准

- 所有阻断环境用例通过，阻断缺陷为 0；
- 100/125/150/200% DPI 与左右/上下双屏都有证据；
- 重复启动、异常重建、开机启动撤销和托盘退出均通过；
- 八小时运行无崩溃，性能数据与异常日志完成脱敏归档；
- Gate A 需要阶段 0 的命中测试、自主移动和焦点标准一起满足；仅完成本计划不能自动宣布 Gate A 通过。

## 证据与缺陷

证据保存到 CI Artifact 或受控测试存储，仓库只提交脱敏索引。文件名使用 `YYYY-MM-DD_commit_environment_case-id`。失败必须记录复现步骤、实际结果、日志时间范围和修复 commit；不得提交真实用户名、桌面路径、设备标识或截图中的私人内容。
